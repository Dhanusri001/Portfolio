# Dhanu Sri T — Developer Portfolio

A premium responsive developer portfolio built using only:
- HTML
- CSS
- Vanilla JavaScript
- Canvas API

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Files

- `index.html` — semantic page structure and content
- `style.css` — responsive design, animations and visual system
- `script.js` — interactions, canvas particles, modal, navigation, validation

## Personal links

Update GitHub, LinkedIn, resume and project URLs in `index.html` / `script.js` when the real URLs are available.

## Resume

## Visual theme

Minimal black/charcoal base with crisp crimson-red accents, editorial typography, sharp borders and restrained motion.
